# Energized Superconductive Interface

<Row>
  <BlockImage id="neoecoprototype1201:superconductive_interface" scale="3"></BlockImage>
</Row>

The higher tier of the two interfaces: the same layout as the [L1 Powered ME Interface](powered_interface.md)
- AE2's nine config slots and nine stock slots, AE2's own panel - but **one marker stocks 8,192 items**, and
for fluids and chemicals it stocks **128 times** AE2's own per-marker amount (AE2 caps an item marker at one
stack of 64, so 8192 is that same widening). Partitioning and setting it up is the same as any ME Interface.

It idles at **0 AE/t**, and 4,000 AE/t is usually higher than every other passive generator in the network,
so one of these takes over its passive generation.

Cards: the same allowance as the powered one - **one crafting card, one fuzzy card**, and with AppliedFlux
installed **one induction card**.

It is assembled in eco's <ItemLink id="neoecoae:integrated_working_station" /> from 1 Cryotheum Crystal,
4 [L1 Powered ME Interfaces](powered_interface.md), 9 Energized Superconductive Ingots and 4 Superconducting
Processors, for 10,000 FE.
