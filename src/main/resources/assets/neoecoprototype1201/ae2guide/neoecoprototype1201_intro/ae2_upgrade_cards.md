# AE2 to L1 Upgrade Cards

Use a card on the matching AE2 block to replace it with the corresponding addon provider or interface in place - existing patterns or interface settings are carried over. No block is ever dropped on the ground by the swap.

| Card | Converts to |
|---|---|
| <ItemImage id="neoecoprototype1201:ae2_pattern_provider_to_l1_card" scale="3" /> | L1 Pattern Provider |
| <ItemImage id="neoecoprototype1201:ae2_interface_to_l1_powered_card" scale="3" /> | L1 Powered Interface |
| <ItemImage id="neoecoprototype1201:ae2_interface_to_l1_superconductive_card" scale="3" /> | Energized Superconductive Interface |

On this line all three cards also upgrade the **cable form**: right-click the cable part the same way. The two interface cards carry their own cable faces now - see [L1 Interfaces](interfaces.md) - so a powered or superconductive interface swaps to its cable face in place, and the cable forms open AE2's own interface screen like the blocks do.

## Recipes

The pattern provider card has two shapeless recipes: use either the block-form or the cable-form pattern provider with any metal ingot to make the same card. Each interface card has one - its block form plus any metal ingot; the cable-form recipes follow the parts when those arrive.
