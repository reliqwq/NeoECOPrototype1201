# 小宗存储矩阵

**小宗存储矩阵**是<ItemLink id="ae2:drive" />那一族里的极端成员：每种近乎无限，默认 **3 种**，用扩展卡升到 **10 种**。

| 项目 | 数值 |
|------|------|
| 类型上限 | 3，装上扩展卡 10 |
| 单类型容量 | （终端里显示成 9.2E） |
| 需要的前置 | MEGA Cells（2.4.6） |

## 分区

在 AE2 的元件工作台里编辑；流体盘按流体自己的键类型分区。

## 升到 10 种

在**工作台**里把盘与**扩展卡**一起合成（卡被吃掉，不退东西；1M 元件留在盘里）。扩展卡配方：4 绿晶晶格 + 4 颗 MEGA Cells 1M 元件 + 1 盈能超导锭。

## 拆回

物品与流体这两只基础盘都可以拆回，退回自己的外壳与一颗 MEGA Cells 1M 元件。
> **注意**：**两只扩展版都没有拆解配方**，扩展版不支持拆卸。

## 这一族包含

> 下面这些物品**只有装了 MEGA Cells 才会注册**，没装时它们根本不存在。

| 名字 | 是哪一类 |
| --- | --- |
| ECO - L1 小宗存储矩阵（3种类型） | 物品盘，基础 |
| ECO - L1 小宗扩展存储矩阵（10种类型） | 物品盘，装卡后的产物 |
| ECO - L1 小宗流体存储矩阵（3种类型） | 流体盘，基础 |
| ECO - L1 小宗流体扩展存储矩阵（10种类型） | 流体盘，装卡后的产物 |
| L1 小宗扩展卡 | 3 种升到 10 种用的卡，配方见上一节 |
| ECO - L1 小宗存储矩阵外壳 | 物品盘的外壳 |
| ECO - L1 小宗流体存储矩阵外壳 | 流体盘的外壳 |
