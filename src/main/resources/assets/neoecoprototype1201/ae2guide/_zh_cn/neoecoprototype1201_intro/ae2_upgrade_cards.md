# AE2 转 L1 升级卡

与扩展ae等模组类似，接受从样板供应器到L1样板供应器的升级。

| 升级卡 | 转换为 |
|---|---|
| <ItemImage id="neoecoprototype1201:ae2_pattern_provider_to_l1_card" scale="3" /> | L1 样板供应器 |
| <ItemImage id="neoecoprototype1201:ae2_interface_to_l1_powered_card" scale="3" /> | L1 供能接口 |
| <ItemImage id="neoecoprototype1201:ae2_interface_to_l1_superconductive_card" scale="3" /> | 盈能超导接口 |


## 配方

依旧方块形态加任意金属锭。
